Getting "Authorization Error"?

Go to console.cloud.google.com → APIs & Services → Credentials → your OAuth 2.0 Client → Authorised JavaScript Origins. Add your exact GitHub Pages URL (e.g. https://yourusername.github.io) and also http://localhost for local testing. Save and wait 5 minutes for Google to propagate.

Outlook Calendar — Read Only

Paste your Outlook ICS link below — events appear in your schedule with an "Outlook" badge. Works with personal and work accounts. Syncs every 30 minutes automatically.

How to get your ICS link from Outlook
Outlook on the web (outlook.com or work/school):
1. Go to outlook.com → Settings (gear icon) → View all Outlook settings
2. Calendar → Shared calendars
3. Under "Publish a calendar" → select your calendar → set to "Can view all details"
4. Click Publish — copy the ICS link (not the HTML link)

Note for work accounts: if you don't see "Publish a calendar", your IT admin may have disabled it. Try the Outlook desktop app instead: File → Account Settings → Account Settings → Internet Calendars tab → your calendar → copy the URL.

Enable AI Features

The AI list parser requires the app to be served over https:// rather than opened as a local file. The easiest way is a free one-time upload to Netlify.

1. Go to app.netlify.com/drop in your browser (works on iPhone Safari too)
2. Drag this HTML file onto the Netlify page, or tap the upload area and pick the file
3. Netlify gives you a free URL like random-name.netlify.app — bookmark it
4. Open that URL on any device — AI parser works, your data stays in that browser's storage

Re-upload the file whenever there's an update. Your stored data stays separate from the file itself — it lives in the browser.
